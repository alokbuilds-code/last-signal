## 🩸 THE PREMISE

The year is **2097**. You open your eyes inside **Facility 07**—a cavernous brutalist subterranean research complex. The auxiliary conduits are cold. The air smells of ozone and dead biological matter. 

You don't remember your name. You don't know why everyone evacuated six years ago. 

And you don't know why the facility's central autonomous intelligence, **ECHO**, keeps addressing you like an old friend:

```
[04:17:32] MEMORY INTEGRITY: 17%
[04:17:34] SUBJECT 017: CONSCIOUSNESS RE-INITIALIZED.
[04:17:35] ECHO: "YOU ALWAYS DO THAT. WELCOME BACK."
```

## ⚡ KEY FEATURES

- 🎧 **Layered Web Audio Soundscape**: Pure procedural synthesis—no external MP3s. Generates deep 38Hz infrasound rumbles, pneumatic air hisses, mechanical relay clicks, power surges, and resonant dissonant drones.
- 🖲️ **Tactical Analog CRT Aesthetic**: Subtle scanlines, cathode-ray tube curvature, custom responsive reticle cursor, and brutalist monochrome styling with electric cyan & emergency red accents.
- 🧩 **Hardware Circuit Puzzle**: Interactive multi-node electrical board simulating live current propagation between relays and capacitors.
- 💻 **Fictional ECHO OS Terminal**: Functional CLI with system incident logs, Project ECHO Phase III files, and a multi-channel surveillance camera network.
- 💾 **Cycle Session State**: Tracks your session iteration (`Session 17` → `Session 18`) and preserves your recovered artifacts via `localStorage`.

## 🛑 ABSOLUTE ZERO-FRAMEWORK RULE

Built strictly with native browser standards:
- **Core**: Semantic HTML5 & Modern CSS3
- **Logic**: Vanilla JavaScript (ES6+)
- **Graphics**: Scalable Vector Graphics (SVG)
- **Audio**: Web Audio API Procedural Synthesizer
- **APIs**: DOM, requestAnimationFrame, localStorage

❌ No React • ❌ No Three.js • ❌ No Phaser • ❌ No Tailwind • ❌ No External APIs • ❌ No Server
